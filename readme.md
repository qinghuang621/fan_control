# C 板风扇控制固件说明

基于 STM32F407 的 C 型开发板固件，当前目标是把风机控制、FG 脉冲反馈采样、PWM 输出控制和 RS485 Modbus 从站能力统一落到一个板卡上，并最终让上层 EBS-P300 / ROS2 节点通过总线访问该设备。

## 1. 项目概述

本项目面向 RoboMaster C 型开发板，完成的核心能力包括：

- 4 路 FG 反馈输入：对应风机 1~4 的转速反馈。
- 3 路同步 PWM 输出：对应风机 1~3 控制，以及风机 4 共用 PWM7 输出。
- 20 kHz 风机控制波形输出。
- RS485 Modbus RTU 从站接口，供 EBS-P300 / ROS2 上位机访问。
- USB CDC 调试输出，便于开发和现场排查。
- 采用主循环驱动的简单状态机，当前还未完全移植 running 项目的 FreeRTOS 多任务框架。

## 2. 硬件连接

### 2.1 PWM/FG 资源映射

| 接口 | 定时器通道 | STM32 引脚 | 功能 | 对应风机 |
|------|------------|-----------|------|----------|
| PWM1 | TIM1_CH1 | PE9 | FG 输入捕获 | 风机 1 反馈 |
| PWM2 | TIM1_CH2 | PE11 | FG 输入捕获 | 风机 2 反馈 |
| PWM3 | TIM1_CH3 | PE13 | FG 输入捕获 | 风机 3 反馈 |
| PWM4 | TIM1_CH4 | PE14 | FG 输入捕获 | 风机 4 反馈 |
| PWM5 | TIM8_CH1 | PC6 | PWM 输出 | 风机 1 控制 |
| PWM6 | TIM8_CH2 | PI6 | PWM 输出 | 风机 2 控制 |
| PWM7 | TIM8_CH3 | PI7 | PWM 输出 | 风机 3 + 风机 4 共用控制 |

### 2.2 连接关系（必须保持）

- 1/5 是风机 1。
- 2/6 是风机 2。
- 3/7 是风机 3。
- 4/7 是风机 4。
- 7 口同时控制风机 3 和风机 4，两个风机共用同一路 PWM 输出。

### 2.3 RS485 接线

| 信号 | 引脚 | 说明 |
|------|------|------|
| RS485_TX | PA2 | USART2 TX，连接 SP3485 DI |
| RS485_RX | PA3 | USART2 RX，连接 SP3485 RO |
| RS485_RE/DE | PG8 | 高电平发送，低电平接收 |

- 默认串口参数：115200, 8N1
- 默认从站地址：1
- A 接 A，B 接 B，不能交叉

### 2.4 FG 输入上拉说明

- 反馈输入使用 STM32 内部上拉（GPIO_PULLUP）
- 适合 FG/开集电极型信号
- 前提是外部信号必须兼容 3.3V 电平；若使用 5V 信号，需要做电平转换

## 3. 支持的 Modbus 功能码

| 功能码 | 名称 | 说明 |
|--------|------|------|
| 0x03 | Read Holding Registers | 读取保持寄存器 |
| 0x04 | Read Input Registers | 读取输入寄存器（当前复用保持寄存器语义） |
| 0x06 | Write Single Register | 单寄存器写入 |
| 0x10 | Write Multiple Registers | 多寄存器写入 |

- 单次读取长度受 PDU 限制，通常不超过 123 个寄存器
- 越界写入/读取会返回异常码 0x02（非法地址）

## 4. 保持寄存器地址映射

> Modbus 主站工具通常使用 PLC 地址（1-based），即协议地址 0 对应 PLC 地址 40001。

| 协议地址 (0-based) | PLC 地址 | 名称 | 读 | 写 | 断电保持 |
|--------------------|----------|------|----|----|----------|
| 0x0000 ~ 0x003F | 40001 ~ 40064 | 控制/命令区 | 是 | 是 | 否 |
| 0x0040 ~ 0x008F | 40065 ~ 40144 | 状态区 | 是 | 否 | 否 |
| 0x0090 ~ 0x00BF | 40145 ~ 40192 | 参数区 | 是 | 是 | 是 |
| 0x00C0 ~ 0x00FF | 40193 ~ 40256 | 保留区 | 是 | 是 | 否 |

### 4.1 控制区（风机占空比/控制）

当前控制区长 4 个寄存器，分别对应 4 个风机的目标占空比：

| 协议地址 | PLC 地址 | 名称 | 说明 |
|----------|----------|------|------|
| 0x0000 | 40001 | FAN1_DUTY | 风机 1 目标占空比，0~100 |
| 0x0001 | 40002 | FAN2_DUTY | 风机 2 目标占空比，0~100 |
| 0x0002 | 40003 | FAN3_DUTY | 风机 3 目标占空比，0~100 |
| 0x0003 | 40004 | FAN4_DUTY | 风机 4 目标占空比，0~100 |

- 代码里会把这些寄存器同步写入 PWM 控制输出
- 若写入大于 100，会被截断到 100

### 4.2 状态区（只读）

状态区按照每个风机 10 个寄存器保留，当前用于反馈风机状态：

| 风机 | 起始协议地址 | PLC 地址 | 说明 |
|------|---------------|----------|------|
| 风机 1 | 0x0064 | 40101 ~ 40110 | 风机 1 状态区 |
| 风机 2 | 0x006E | 40111 ~ 40120 | 风机 2 状态区 |
| 风机 3 | 0x0078 | 40121 ~ 40130 | 风机 3 状态区 |
| 风机 4 | 0x0082 | 40131 ~ 40140 | 风机 4 状态区 |

每个风机 10 寄存器布局如下：

| 偏移 | 名称 | 类型 | 说明 |
|------|------|------|------|
| +0 | ERR | uint16 | 0=停止，1=运行，其他可扩展故障码 |
| +1 | 保留 | uint16 | 始终为 0 |
| +2/+3 | POS | float32 | 近似位置/脉冲累计 |
| +4/+5 | VEL | float32 | 速度（RPM 近似） |
| +6/+7 | T | float32 | 占空比/功率估计 |
| +8 | T_MOS | uint16 | MOS 温度估计 |
| +9 | T_Rotor | uint16 | 转子温度估计 |

> 其中 `POS`、`VEL`、`T` 采用 32 位小端浮点存放，高字在前、低字在后。

### 4.3 参数区（用户配置 / 断电保持）

参数区位于 0x0090 ~ 0x00BF，分成固定配置和保留参数：

| 协议地址 | PLC 地址 | 名称 | 说明 |
|----------|----------|------|------|
| 0x0090 | 40145 | UART_CFG | 串口参数枚举 |
| 0x0091 | 40146 | SLAVE_ADDR | Modbus 从站地址，默认 1 |
| 0x0092 ~ 0x00BF | 40147 ~ 40192 | 用户参数 | 可扩展配置，带断电保持 |

- 断电保持逻辑使用 Flash A/B 双区交替写入，带 magic/version/seq/CRC32 校验
- 只有参数区会触发延迟 2 秒落盘
- 0x0091 写入 0 或大于 247 时，自动回退为 1

## 5. EBS-P300 / ROS2 接入方式

### 5.1 目标架构

C 板本身不承担 ROS2 运行环境，而是作为 RS485 设备节点、Modbus 从站和本地控制单元：

- C 板：负责四路 FG 采集、PWM 输出、状态回传、Modbus 读写
- EBS-P300 / ROS2：负责上层协议聚合、统一状态发布、风机控制命令下发和联动逻辑

推荐拆分为多节点：

- `fan_bus_node`：RS485 收发、Modbus 解析、CRC 校验、站号管理
- `fan_state_node`：发布风机 RPM、占空比、脉冲累计和故障状态
- `fan_cmd_node`：下发控制目标值、限幅和安全保护
- `ebs_bridge_node`：连接 EBS-P300 侧的更高层策略/状态汇总

### 5.2 通信语义

- 上层通过 RS485 Modbus 访问寄存器
- 设备用 `0x0000~0x0003` 作为风机目标占空比控制入口
- 上层读 `0x0040~0x008F` 获取状态区
- 参数区 `0x0090~0x0091` 可以调节串口参数与站号

这与当前 running 工程的地址规划保持一致，便于后续复用现有的上位机和 ROS2 接口设计。

## 6. PWM/FG 运行逻辑

### 6.1 反馈采样

- TIM1_CH1~CH4 采集四路 FG 脉冲
- 代码会对每路输入执行计数与 500ms 测频
- 通过 `pulse_get_rpm()` / `pulse_get_freq_hz()` / `pulse_get_pulse_count()` 读取数据

### 6.2 PWM 控制输出

- TIM8_CH1~CH3 同步输出 20 kHz PWM
- 所有通道使用同一频率与相同的占空比控制策略
- 风机 1/2 单独对应 PWM5/PWM6
- 风机 3/4 共用 PWM7

## 7. 构建与烧录

使用 CMake 构建：

```powershell
cmake --preset Debug
cmake --build --preset Debug --parallel 4
```

编译完成后会生成：

- `.elf`
- `.hex`
- `.bin`

可以使用 STM32 烧录工具将固件下载到 C 板。
